# Ticket 05: Configure GitHub Actions for Playwright CI

## Summary
Set up the GitHub Actions workflow to run Playwright tests on every push and PR, including a PostgreSQL service container.

## Why
Running tests in CI prevents broken code from reaching production. The auto-generated workflow from Playwright setup (ticket 01) needs a database service added.

## Steps

### 1. Update `.github/workflows/playwright.yml`

The file generated by `npm init playwright` needs a PostgreSQL service. Replace or update it:

```yaml
name: Playwright Tests

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  test:
    runs-on: ubuntu-latest

    services:
      postgres:
        image: postgres:16
        env:
          POSTGRES_USER: postgres
          POSTGRES_PASSWORD: postgres
          POSTGRES_DB: ScoreBoard_test
        ports:
          - 5432:5432
        options: >-
          --health-cmd pg_isready
          --health-interval 10s
          --health-timeout 5s
          --health-retries 5

    env:
      DATABASE_URL: postgresql://postgres:postgres@localhost:5432/ScoreBoard_test
      NODE_ENV: development

    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-node@v4
        with:
          node-version: 20

      - name: Install dependencies
        run: npm ci

      - name: Create base tables
        run: |
          psql $DATABASE_URL -c "
            CREATE TABLE IF NOT EXISTS single_game_results (
              id SERIAL PRIMARY KEY,
              date TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
              winner TEXT NOT NULL,
              loser TEXT NOT NULL
            );
            CREATE TABLE IF NOT EXISTS team_game_results (
              id SERIAL PRIMARY KEY,
              date TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
              winner_attack TEXT NOT NULL,
              winner_defense TEXT NOT NULL,
              loser_attack TEXT NOT NULL,
              loser_defense TEXT NOT NULL
            );
          "

      - name: Install Playwright browsers
        run: npx playwright install --with-deps

      - name: Run Playwright tests
        run: npx playwright test

      - uses: actions/upload-artifact@v4
        if: ${{ !cancelled() }}
        with:
          name: playwright-report
          path: playwright-report/
          retention-days: 30
```

### 2. Verify
- Push a branch and open a PR to see the workflow run
- Check that the PostgreSQL service starts, base tables are created, migrations run (via the app startup), and tests pass

## Notes
- Base tables are created manually in the workflow because they predate the migration system (same as local setup)
- The migrations run automatically when the Node server starts via `webServer` in the Playwright config
- Test artifacts (screenshots, traces) are uploaded on failure for debugging
